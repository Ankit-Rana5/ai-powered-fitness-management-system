# 🏋️ AI-Powered Fitness Management System

The AI-Powered Fitness Management System is a scalable full-stack application built using Java Spring Boot Microservices and React.js. 
The system enables users to manage fitness activities, monitor health progress, and receive personalized AI-powered fitness recommendations.
It follows a Microservices architecture with event-driven communication using Apache Kafka and integrates Google Gemini AI to deliver intelligent health insights. 
The project is designed using modern backend development practices, RESTful APIs, Docker, and PostgreSQL, 
making it suitable for enterprise-level applications.
